# README

The file names follow the Fourier decomposition, with a `c` prefix for *cosine* and `s` for *sine*. The smaller the following number, the lower the frequency of the wave.

The combos use arbitrary weights. For the first combination, I used $0.8 \times s_1 + 0.5 \times s_{10}$. For the second, I used $0.5 \times c_1 + 0.2 \times s_2$. The fitted line uses weights of approximately ${\bf w} = (0.83, 0.16, 0.53, -0.64)^\top$.
